# Vicon Creator — Viktoriia Loskutova

Многостраничный сайт фотографа. 28 страниц на английском и 28 на нидерландском, плюс страница 404. Сайт собран на предоставленных фотографиях и видео. Оригинальный архив не изменён.

## Что входит

- Главная, портфолио, свадьбы, loveshoot, портреты, Motherhood (беременность и postpartum), дети и семья, события; отдельная страница postpartum / kraamreportage.
- Страница Виктории с фотографиями из `me`, ориентиры по ценам, модальное окно записи и основной Instagram.
- География Нидерландов, отдельные страницы свадебной фотографии в Амстердаме, loveshoot в Гааге и свадеб в Бельгии по предварительной договорённости.
- 69 отобранных фотографий. У адаптивных изображений есть облегчённые версии, размеры и содержательный alt-текст на языке страницы. Цветокоррекция оригиналов сохранена.
- 5 клипов. Звуковые дорожки удалены физически, видео также имеют `muted` и запускаются пользователем. Портретный клип развёрнут в естественную ориентацию.
- Согласованная типографика Cormorant Garamond / Manrope. Шрифты размещены локально, лицензии находятся рядом с ними.
- Общая композиционная система с палитрами по сериям: кремовая, оливковая, графитовая, мягкая тёплая, земляная и тёмная сливовая.
- Галерея с клавиатурой, закрытием Escape, свайпами и возвратом фокуса. Мобильное меню и переключение EN/NL с сохранением текущего раздела.
- Уникальные title и description, canonical, hreflang, sitemap.xml, sitemap-images.xml, структурированные данные организации, фотографа, изображений, услуг и хлебных крошек. Основное содержание находится в HTML и не требует JavaScript.
- В подвале Vicon Creator и KVK 97270725. Домашний адрес не опубликован. Нет выдуманных отзывов, наград, клиентов или дат съёмок.

## Материалы и ограничения

В архиве было 80 фотографий и 14 mp4. Некоторые файлы дублировали кадры, содержали готовые коллажи или представляли собой неподвижное изображение с музыкой. Для портфолио сделан отбор. После исходного архива добавлены ещё 10 снимков Motherhood и 7 Events. Исходный кадр беременности из `portrait` сохранён на обложке Motherhood; новую серию можно открыть в галерее и на странице postpartum. На географических страницах снимкам не приписаны неподтверждённые места съёмки.

Для GitHub Pages в комплекте есть автоматическая сборка `.github/workflows/pages.yml`. Она подставляет фактический адрес сайта в canonical, hreflang, sitemap и структурированные данные и включает индексацию. Относительные ссылки работают как в репозитории (`username.github.io/repository/`), так и с собственным доменом. До этой сборки `dist` — предварительная версия с отключённой индексацией.

Подготовлена карта 360 формулировок в 23 группах на основе поисковой выборки, сайтов фотографов и рекомендаций Google. Частотность запросов в Keyword Planner / Semrush пока не измерялась. Источники и ограничения исследования находятся в `seo/SEO-REPORT.md`, карта — в `seo/keyword-map.json`, список для измерения спроса — в `seo/keyword-planner-import.txt`. Позиции в поиске не гарантируются; сайт не содержит массовых копий страниц с подстановкой города.

## Редактирование

Основные тексты и маршруты находятся в `src/content.py`, новые городские страницы и памятки — в `src/seo_content.py`, шаблоны — в `src/generate.py`, форма — в `src/booking.py`, стили и взаимодействия — в `dist/assets/`. Для сборки нужен Python 3.12 или новее, без дополнительных пакетов:

```sh
python3 src/generate.py --origin https://YOUR-DOMAIN --index --portable
```

`dist` — готовый сайт. Для локального просмотра: `python3 -m http.server 8000 --directory dist`, затем откройте http://localhost:8000. Не открывайте HTML двойным кликом: форма использует JavaScript-модули, которым нужен HTTP.

## Загрузка на GitHub Pages

1. Распакуйте ZIP. Создайте репозиторий GitHub и загрузите **содержимое** папки `Vicon-Creator-GitHub`, включая `.github`, `src`, `seo` и `dist`. При обновлении действующего сайта следуйте `seo/LAUNCH.md` и сохраните собственный CNAME и актуальный адрес обработчика заявок, если уже меняли их. Сам ZIP на сайт загружать не нужно.
2. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Deploy Vicon Creator → Run workflow** и дождитесь завершения. При следующих изменениях ветки main или master сборка запускается автоматически.
4. Адрес опубликованного сайта появится в Settings → Pages. Первые результаты в поиске появятся только после обхода поисковиками; сроки и позиции не гарантируются.
5. После покупки домена добавьте его в Settings → Pages → Custom domain и настройте DNS по инструкции GitHub. Повторно запустите workflow, чтобы SEO-адреса обновились.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Если загружаете через веб-интерфейс GitHub, убедитесь, что скрытая папка `.github/workflows` тоже попала в репозиторий. Для больших загрузок удобнее GitHub Desktop. Нужен именно режим GitHub Actions: не выбирайте публикацию корня репозитория, поскольку сайт находится в `dist`.

## Форма записи

Отдельное модальное окно на EN/NL: имя, тип фотосессии, «Другое» с собственной идеей, желаемая дата и способ связи. Поддерживаются Telegram, WhatsApp, email, звонок и Instagram; после выбора появляется соответствующее поле. Прошедшие даты и некорректные данные отклоняются. Дата является пожеланием, а не автоматическим бронированием.

В `dist/assets/booking-config.mjs` установлен предоставленный вами новый адрес отдельного Google Apps Script для Vicon Creator: `https://script.google.com/macros/s/AKfycbwc5TnVAN_dNMsA_DZc3wloOLpOZ67w-x3vCXCXZFK7YiGyV2R_zDRDrtTnqh7RibDD/exec`. Отправляются совместимые поля `name`, `reply_to`, `service`, `message`, `page_url`, `submitted_at`, `website`. Метка `Vicon Creator booking` позволяет отличить заявки фотографа. Выбранный способ связи означает, как клиент хочет получить ответ; новый обработчик сохраняет заявки в Website leads и уведомляет фотографа по email и Telegram.

Токен бота находится только в Script Properties вашего Apps Script и в ZIP не включён. Вы уже настроили фотографа получателем и подтвердили наличие записей в Website leads. Для смены домена повторная настройка получателей не нужна. Новая категория Postpartum / mother & baby передаётся через те же совместимые поля.

Из-за режима no-cors браузер не получает подтверждение от обработчика о доставке в Telegram/email. Форма сообщает об отправке запроса и необходимости личного подтверждения. При этом обновлении новые тестовые заявки не отправлялись по вашему указанию; вы подтвердили работу таблицы самостоятельно. При сетевой ошибке данные остаются в форме, рядом доступен основной Instagram.

### Как выложить именно эту версию

1. Распакуйте Vicon-Creator-Final.zip. Внутри папки Vicon-Creator-GitHub лежат исходники и готовые страницы.
2. В GitHub Desktop откройте локальную папку своего репозитория. Скопируйте в неё **содержимое** Vicon-Creator-GitHub с заменой файлов, включая .github/workflows/pages.yml. Свою CNAME оставьте, если она уже есть.
3. Нажмите Commit to main → Push origin.
4. В GitHub: Settings → Pages → Source = GitHub Actions. Дождитесь успешного Deploy Vicon Creator во вкладке Actions.

Не публикуйте корень как обычную ветку: workflow собирает папку dist с реальным адресом и включённой индексацией. Вложенная папка-обёртка в репозитории не нужна. После покупки домена задайте его в Pages и повторно запустите workflow.
