# Vicon Creator — Viktoriia Loskutova

Многостраничный сайт фотографа. 16 страниц на английском и 16 на нидерландском, плюс страница 404. Сайт собран на предоставленных фотографиях и видео. Оригинальный архив не изменён.

## Что входит

- Главная, портфолио, свадьбы, loveshoot, портреты, беременность, дети и семья, события.
- Страница Виктории с фотографиями из `me`, ориентиры по ценам, модальное окно записи и основной Instagram.
- География Нидерландов, отдельные страницы свадебной фотографии в Амстердаме, loveshoot в Гааге и свадеб в Бельгии по предварительной договорённости.
- 52 отобранные фотографии. У адаптивных изображений есть облегчённые версии, размеры и содержательный alt-текст на языке страницы. Цветокоррекция оригиналов сохранена.
- 5 клипов. Звуковые дорожки удалены физически, видео также имеют `muted` и запускаются пользователем. Портретный клип развёрнут в естественную ориентацию.
- Согласованная типографика Cormorant Garamond / Manrope. Шрифты размещены локально, лицензии находятся рядом с ними.
- Общая композиционная система с палитрами по сериям: кремовая, оливковая, графитовая, мягкая тёплая, земляная и тёмная сливовая.
- Галерея с клавиатурой, закрытием Escape, свайпами и возвратом фокуса. Мобильное меню и переключение EN/NL с сохранением текущего раздела.
- Уникальные title и description, canonical, hreflang, sitemap.xml, структурированные данные организации, услуг и хлебных крошек. Основное содержание находится в HTML и не требует JavaScript.
- В подвале Vicon Creator и KVK 97270725. Домашний адрес не опубликован. Нет выдуманных отзывов, наград, клиентов или дат съёмок.

## Материалы и ограничения

В архиве было 80 фотографий и 14 mp4. Некоторые файлы дублировали кадры, содержали готовые коллажи или представляли собой неподвижное изображение с музыкой. Для портфолио сделан отбор. Единственный отдельный беременный портрет найден среди `portrait`, поэтому страница беременности построена вокруг него без выдуманной дополнительной серии. На географических страницах снимкам не приписаны неподтверждённые места съёмки.

Для GitHub Pages в комплекте есть автоматическая сборка `.github/workflows/pages.yml`. Она подставляет фактический адрес сайта в canonical, hreflang, sitemap и структурированные данные и включает индексацию. Относительные ссылки работают как в репозитории (`username.github.io/repository/`), так и с собственным доменом. До этой сборки `dist` — предварительная версия с отключённой индексацией и техническим заполнителем https://example.invalid в SEO-адресах. GitHub Actions автоматически заменит его реальным адресом; вручную менять его перед загрузкой не нужно.

Частотность запросов в Keyword Planner / Ahrefs не измерялась. Семантика построена по направлениям, естественной терминологии EN/NL и географии. Позиции в поиске не гарантируются; сайт не содержит массовых копий страниц с подстановкой города.

## Редактирование

Основные тексты и маршруты находятся в `src/content.py`, шаблоны — в `src/generate.py`, форма — в `src/booking.py`, стили и взаимодействия — в `dist/assets/`. Для сборки нужен Python 3.12 или новее, без дополнительных пакетов:

```sh
python3 src/generate.py --origin https://YOUR-DOMAIN --index --portable
```

`dist` — готовый сайт. Для локального просмотра: `python3 -m http.server 8000 --directory dist`, затем откройте http://localhost:8000. Не открывайте HTML двойным кликом: форма использует JavaScript-модули, которым нужен HTTP.

## Загрузка на GitHub Pages

1. Распакуйте ZIP. Создайте репозиторий GitHub и загрузите **содержимое** папки `Vicon-Creator-GitHub`, включая `.github`, `src` и `dist`. Сам ZIP на сайт загружать не нужно.
2. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Deploy Vicon Creator → Run workflow** и дождитесь завершения. При следующих изменениях ветки main или master сборка запускается автоматически.
4. Адрес опубликованного сайта появится в Settings → Pages. Первые результаты в поиске появятся только после обхода поисковиками; сроки и позиции не гарантируются.
5. После покупки домена добавьте его в Settings → Pages → Custom domain и настройте DNS по инструкции GitHub. Повторно запустите workflow, чтобы SEO-адреса обновились.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Если загружаете через веб-интерфейс GitHub, убедитесь, что скрытая папка `.github/workflows` тоже попала в репозиторий. Для больших загрузок удобнее GitHub Desktop. Нужен именно режим GitHub Actions: не выбирайте публикацию корня репозитория, поскольку сайт находится в `dist`.

## Форма записи

Отдельное модальное окно на EN/NL: имя, тип фотосессии, «Другое» с собственной идеей, желаемая дата и способ связи. Поддерживаются Telegram, WhatsApp, email, звонок и Instagram; после выбора появляется соответствующее поле. Прошедшие даты и некорректные данные отклоняются. Дата является пожеланием, а не автоматическим бронированием.

В `dist/assets/booking-config.mjs` установлен прежний публичный адрес Google Apps Script из интеграции Loskutov / Smartlinkella. Отправляются совместимые поля `name`, `reply_to`, `service`, `message`, `page_url`, `submitted_at`, `website`. Метка `Vicon Creator booking` позволяет отличить заявки фотографа. Выбранный способ связи означает, как клиент хочет получить ответ; уведомления идут по прежней серверной схеме.

Токены бота остаются на стороне существующего обработчика и в ZIP не включены. Смена домена сама по себе не меняет получателя: позже нужно обновить настройки получателей в Apps Script либо указать новый endpoint в booking-config.mjs.

Из-за режима no-cors браузер не получает подтверждение от обработчика о доставке в Telegram/email. Форма сообщает об отправке запроса и необходимости личного подтверждения. Настоящие тестовые заявки не отправлялись; доставку нужно проверить владельцу после публикации одной реальной пробной заявкой. При сетевой ошибке данные остаются в форме, рядом доступен основной Instagram.
