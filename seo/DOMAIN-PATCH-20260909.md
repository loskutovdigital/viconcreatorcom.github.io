# Vicon Creator: патч основного домена

Основной адрес: **https://viconcreator.com**. Дата: 9 сентября 2026.

## Как применить

1. Распакуйте `Vicon-Creator-Domain-Patch.zip`.
2. Откройте папку `PATCH` в архиве. Скопируйте её **содержимое** в локальный корень существующего GitHub-репозитория — туда, где уже лежат `src`, `dist` и `.github`. Саму папку `PATCH` внутрь репозитория не добавляйте.
3. Разрешите замену совпадающих файлов и слияние папок. **Не удаляйте прежние папки целиком:** патч не содержит фотографий, видео и остальных неизменённых ресурсов.
4. В GitHub Desktop: **Commit to main → Push origin**. Если ваша ветка называется master, используйте её. Во вкладке GitHub **Actions** дождитесь успешного **Deploy Vicon Creator**. В Settings → Pages источник публикации — GitHub Actions; основной домен — viconcreator.com.
5. После публикации отправьте в Google Search Console карты сайта:
   - https://viconcreator.com/sitemap.xml
   - https://viconcreator.com/sitemap-images.xml

Патч подготовлен для последней версии сайта от 7 сентября: Motherhood/postpartum, новые снимки событий, отдельный обработчик заявок и аналитика без всплывающего вопроса. Для установки не требуется повторно загружать медиатеку.

## Что исправлено

- Основной домен в `src/content.py` теперь `https://viconcreator.com`.
- Все собственные абсолютные URL в canonical, hreflang, Open Graph и JSON-LD пересобраны для этого домена.
- `sitemap.xml` содержит 56 существующих страниц с языковыми связями EN / NL / x-default.
- `sitemap-images.xml` содержит 38 страниц и 222 вхождения фотографий. Одна фотография может относиться к нескольким страницам, если она действительно показана на них; это не 222 уникальных снимка.
- Оба XML-файла записаны с переносами строк и отступами.
- `robots.txt` разрешает обход и указывает обе карты на правильном домене. У 56 содержательных страниц разрешена индексация; у страницы ошибки 404 сохранён noindex.
- Добавлен CNAME с viconcreator.com в корне проекта и в публикуемой папке.
- Обычная сборка по умолчанию выпускает публичную версию. Для закрытого предпросмотра есть явный флаг `--no-index`.
- GitHub Actions использует закреплённый домен из исходников. Следующая автоматическая сборка не вернёт технический адрес хостинга.
- Проверка перед публикацией сверяет домен метаданных, адреса обеих карт, языковые пары, наличие файлов и соответствие карты изображений фотографиям на страницах.

## Почему карты лежат в dist

GitHub Actions публикует **содержимое** `dist` как корень сайта:

| Файл проекта | Публичный адрес |
|---|---|
| `dist/index.html` | `https://viconcreator.com/` |
| `dist/sitemap.xml` | `https://viconcreator.com/sitemap.xml` |
| `dist/sitemap-images.xml` | `https://viconcreator.com/sitemap-images.xml` |
| `dist/robots.txt` | `https://viconcreator.com/robots.txt` |

Добавлять `/dist/` к публичным адресам не нужно. Перенос карт в корень исходного репозитория не требуется.

Адреса `www.sitemaps.org`, `www.w3.org` и `www.google.com/schemas/sitemap-image/1.1` внутри XML обозначают стандартные пространства имён. Это не адреса страниц или фотографий, и заменять их на viconcreator.com нельзя. Ссылки на Instagram, Google Analytics, Google Apps Script, справочные сайты и лицензии также сохраняют своё назначение.

## Проверка и границы патча

Локальная проверка прошла: 57 HTML-файлов, включая 404; 28 языковых пар; 56 адресов в sitemap; 38 страниц и 222 изображения в image sitemap; отсутствуют битые внутренние ссылки, повторные title/description и старый собственный домен в готовом сайте. Изображения из карты сверены с существующими файлами и разметкой страниц.

Дизайн, содержимое портфолио, фотографии, видео, получатели заявок, Apps Script и идентификатор аналитики не менялись. Новые заявки не отправлялись.

Это архив для применения к вашему GitHub-репозиторию. Его установка и публикация на viconcreator.com ещё не выполнены из этого чата; прямое чтение живого домена инструментом было недоступно. Успешный локальный аудит не является подтверждением уже обновлённого публичного сайта.
